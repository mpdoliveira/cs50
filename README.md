## What I Built

- **C fundamentals:** exercises covering logic, conditionals, loops, strings, and data manipulation, including `mario-more`, `credit`, `scrabble`, and `readability`.
- **Algorithms and data structures:** sorting, voting systems, recursion, pointers, memory management, and tries, including `plurality`, `tideman`, `inheritance`, and `trie`.
- **Files and images:** image processing and file recovery with `filter-more`, `smiley`, and `recover`.
- **SQL and back-end:** database queries in `songs` and web applications using Python, Flask, and SQLite, such as `birthdays` and `finance`.
- **Web development:** web pages and interactive features built with HTML, CSS, JavaScript, and Bootstrap in `homepage` and `trivia`.
- **Final project — Family Forest:** a web application for adding people and relationships and exploring family connections through an interactive graph, with user authentication and SQLite data storage. Find more about it in my [final project video](https://www.youtube.com/watch?v=weOPSjBXZDo).

## Learning Objectives

Apply core computer science concepts through hands-on problem-solving, algorithms, data structures, memory management, databases, and web development.
